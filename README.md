# Parachute — Narrative Media Project

An interactive narrative project created in p5.js for my Narrative Media course at Georgia Tech. The project reimagines Hayley Williams' Parachute by turning the song's central metaphor of falling in love into a literal interactive experience.

The experience begins with a desktop inspired by Hayley Williams' website, where the player discovers and starts the song. The first verse plays like karaoke before the player begins falling through the rest of the lyrics. Each word appears inside a cloud that the player navigates around as the environment shifts from a starry sky, to clear weather, to a storm, and finally back to a calm landing.

Rather than using traditional game objectives, the interaction is meant to make the player experience the narrative—moving through the song while having some control over the fall, but never being able to stop it. When the lyrics reach “Watch me fly,” a parachute appears, bringing the narrative to its conclusion.
